Demo: JSON Formatting & Repair

[Valid JSON]
Input: {"name": "Alice", "age": 30}
Output: {"name": "Alice", "age": 30}

[Markdown fences]
Input: ```json
{"name": "Bob"}
```
Output: {
  "name": "Bob"
}

[Single quotes]
Input: {'name': 'Charlie', 'score': 95}
Output: {
  "name": "Charlie",
  "score": 95
}

[Trailing comma in object]
Input: {"key": "value",}
Output: {
  "key": "value"
}

[Strings with punctuation]
Input: {'message': "don't stop, please", 'items': ['a,b', 'c'],}
Output: {
  "message": "don't stop, please",
  "items": [
    "a,b",
    "c"
  ]
}

[Truly invalid]
Input: This is not JSON at all: ??? {]
Output: {"error": "Không thể phân tích JSON", "raw": "This is not JSON at all: ??? {]"}

[Non-standard constant]
Input: {"score": NaN}
Output: {"error": "Không thể phân tích JSON", "raw": "{\"score\": NaN}"}
